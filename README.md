# Switchit!

큼직한 픽셀 버튼으로 지금 하는 일의 시간을 기록하는 작은 Windows 위젯입니다. 체스 시계처럼 한 번에 한 항목만 시간이 쌓입니다. 따뜻한 크림색 본체와 디지털 표시창, 굴림체 영수증을 사용합니다. 제목 표시줄과 상자 안 설명 문구 없이, 기본 80% 배율과 3개 항목에서 약 354×122 DIP 크기로 표시됩니다.

## 실행

설치형은 [GitHub Releases](https://github.com/dyn0saur/Switchit/releases/latest)에서 `Switchit-Setup-1.0.0-win-x64.exe`를 내려받아 실행합니다. 관리자 권한 없이 사용자 계정에 설치되며, 기본 위치는 `%LOCALAPPDATA%\Programs\Switchit`입니다. 바탕화면 바로가기(기본 선택), 시작 메뉴 바로가기, Windows 앱 제거 항목이 함께 만들어집니다. **Windows 로그인 시 실행**을 선택하면 시작프로그램에도 등록됩니다(기본 해제). 다시 설치할 때 해당 선택을 해제하면 시작프로그램 등록이 제거됩니다. .NET 런타임이 포함된 Windows 10/11 x64용 설치 파일입니다.

배포용 `Switchit-win-x64-self-contained.zip`을 풀고 `Switchit\Switchit.exe`를 실행합니다. **Windows 10/11 x64**용이며 .NET 런타임이 포함되어 있어 별도 설치가 필요하지 않습니다. `Switchit.exe`만 옮기지 말고 폴더 전체를 함께 옮겨 주세요. 프로젝트 안에서는 `dist\Switchit\Switchit.exe`로 실행합니다. 바탕화면 바로가기 이름은 **Switchit!**입니다.

설치 파일 옆의 `.sha256` 파일로 다운로드 무결성을 확인할 수 있습니다. 현재 설치 파일에는 배포자 코드 서명이 없습니다. 앱을 제거해도 업무 설정과 영수증은 보존됩니다.

소스에서 바로 실행하려면 `global.json`에 지정된 .NET SDK 9.0.102 계열이 설치된 환경에서 다음 명령을 사용합니다.

```powershell
powershell -NoProfile -File .\scripts\Run.ps1
```

## 사용 방법

- **휴식 / 업무1 / 업무2**: 새 사용자의 기본 항목입니다. 버튼을 누르면 해당 항목의 시간이 올라가며 시간:분 가운데 콜론(:)이 0.5초마다 꺼졌다 켜집니다. 다른 항목을 누르면 이전 항목은 멈추고 선택한 항목의 시간만 올라갑니다. 같은 버튼을 다시 눌러도 시간이 초기화되지 않습니다. 기존 사용자의 이름과 기록은 유지됩니다.
- **+**: 작업 중에도 새 항목을 추가합니다. 이름과 버튼 색상을 지정할 수 있습니다.
- **항목 우클릭**: 이름·색상을 바꾸거나 항목을 제거합니다. 제거한 항목의 기록 시간은 현재 세션 합계와 영수증에 남습니다.
- **⚙ / Ⅱ / − / ×**: 오른쪽 제어 상자의 설정 / 일시정지 / 최소화 / 닫기입니다. 일시정지 후 항목 버튼을 누르면 기록을 이어 갑니다.
- **종료 → 다시시작**: 현재 세션을 마치고 영수증을 출력하면 같은 버튼이 **다시시작**으로 바뀝니다. 다시 누르면 업무는 유지하고 시간은 0으로 초기화하며 영수증을 접습니다. 이어서 항목을 눌러 측정을 시작합니다.
- **영수증 우클릭**: 영수증 위에 마우스를 올리면 종이가 살짝 밝아지고 하단에 복사 안내가 겹쳐 표시됩니다. 우클릭하면 영수증 텍스트를 복사하고, 영수증 위에 완료 메시지가 잠깐 나타났다 사라집니다.

- **닫기**: 기록을 시작한 뒤 아직 **종료**를 누르지 않았다면, 일시정지 중에도 “기록이 진행중입니다. 닫으시겠습니까?”를 한 번 더 묻습니다. **아니요**를 누르면 기록을 계속하고, **예**를 누르면 등록한 업무와 설정을 저장하고 앱을 닫습니다. 다시 실행하면 업무 이름·색상·순서는 그대로 유지하고, 각 업무 시간과 합계는 모두 **00:00**으로 시작합니다. 이전에 삭제한 업무는 다시 나타나지 않으며, 새로 항목을 눌러야 측정이 시작됩니다.

영수증은 프린터 슬롯의 안쪽 폭과 위치에 맞춰 아래로 펼쳐집니다. 굴림체 글씨 크기는 위젯 배율과 관계없이 일정하며, 종이가 좁으면 내용을 줄바꿈합니다. 긴 영수증은 마우스 휠로 스크롤할 수 있습니다.

**하단 프린터 슬롯이 있는 본체를 잡고 끌어** 위치를 옮깁니다. 항목 표시창과 프린터 옆 합계는 **시간:분(HH:MM)**으로 표시하며, 내부 기록과 영수증은 초까지 유지합니다. 영수증에는 **시간:분:초(HH:MM:SS)**가 나옵니다.

재실행 시 이전 모니터와 실제 픽셀 위치를 기억합니다. 크기가 달라져도 오른쪽 아래를 기준으로 복원하며, 모니터 연결·배치가 달라졌다면 해당 모니터 안의 위치를 유지하거나 가까운 화면 안으로 보정합니다. 위치는 이동 후·주기적 저장 시·정상 종료 시 저장됩니다.

설정 저장 등 일반 알림은 버튼 위쪽에 잠깐 표시되며, 위젯 크기는 변하지 않습니다.

항목이 화면 너비보다 많아지면 항목 영역을 가로로 스크롤할 수 있습니다. 설정·일시정지·종료 버튼은 오른쪽에 계속 표시됩니다. Windows 화면을 잠그거나 PC가 절전 모드로 들어가면 기록을 자동으로 일시정지합니다. 돌아온 뒤 항목을 눌러 다시 시작해 주세요.

## 설정

- **최소 사용 시간**: 다른 업무로 전환하기 전 채워야 하는 업무 시간입니다. 이름이 **휴식**인 항목과 일시정지는 언제든 사용할 수 있으며, 쉬는 시간은 업무의 최소 시간에 포함하지 않습니다. A 업무 → 휴식 → A 업무는 A의 진행 시간을 이어 갑니다. A에서 최소 시간을 채우면 휴식을 거친 뒤에도 B로 전환할 수 있습니다. B로 전환하면 B의 최소 시간이 새로 시작되고, 이후 A로 돌아오면 A에도 다시 최소 시간이 적용됩니다. 최소 시간을 채우기 전에는 휴식·일시정지 중에도 다른 업무로 전환하거나 해당 업무를 삭제할 수 없습니다. **종료는 언제든 가능합니다.** `0`이면 제한이 없습니다.
- **항상 위에 표시**: 다른 일반 창 위에 위젯을 표시합니다.
- **위젯 크기**: 화면에 맞게 50%, 75%, 80%(기본), 100%, 125% 중에서 선택합니다. 크기나 항목 수가 바뀌거나 영수증이 펼쳐질 때 오른쪽 아래 위치를 기준으로 유지합니다. 화면 밖으로 넘어갈 때만 화면 안으로 보정합니다.
- **버튼 효과음**: 항목 전환과 영수증 출력 시 소리를 켜거나 끕니다.

## 기록 저장

업무 목록·설정·위치는 사용자별 `%LOCALAPPDATA%\Switchit` 폴더에 저장합니다. 처음 실행할 때 새 저장 폴더가 없으면 이전 `%LOCALAPPDATA%\WessClock`의 기록을 자동으로 복사합니다. 기존 원본은 남겨 두며 새 폴더에 이미 기록이 있으면 덮어쓰지 않습니다. 이전 버전이 실행 중이면 먼저 닫아야 합니다. 일반 재실행 시 이전 측정 시간은 이어받지 않습니다. 완료된 영수증은 `receipts` 폴더에 텍스트와 JSON으로 보관합니다.

개발·검증용 기록을 일반 기록과 분리하려면 저장 경로를 지정할 수 있습니다.

업데이트 중 현재 기록을 이어야 할 때는 `--resume-session`으로 실행할 수 있습니다. 이 경우 미완료 세션의 누적 시간·실행 항목·최소 시간 진행 상태를 복원하며 앱이 꺼진 시간은 합산하지 않습니다. 일반 실행은 기존처럼 시간을 초기화합니다.

```powershell
.\dist\Switchit\Switchit.exe --data-dir .\.qa\manual
```

## 빌드와 배포

추가 NuGet 라이브러리를 사용하지 않는 WPF / .NET 9 프로젝트입니다.

```powershell
# 배포용: .NET 런타임을 함께 담고 ZIP 생성
powershell -NoProfile -File .\scripts\Publish.ps1 -SelfContained -Zip

# 설치 EXE + ZIP + SHA256 생성
powershell -NoProfile -File .\scripts\Build-Installer.ps1 -Version 1.0.0

# 작은 개발용 빌드: 실행 PC에 .NET Desktop Runtime 9 필요
powershell -NoProfile -File .\scripts\Publish.ps1

# 빌드 후 바탕화면 바로가기 생성
powershell -NoProfile -File .\scripts\Create-Shortcut.ps1
```

자체 포함 빌드를 **만들 때** Microsoft .NET 런타임 패키지 다운로드가 필요할 수 있습니다. 완성된 ZIP 실행에는 다운로드가 필요하지 않습니다. ZIP은 `dist` 폴더에 저장됩니다. 바로가기는 현재 빌드 폴더를 가리키므로 프로젝트를 옮겼다면 다시 생성해 주세요.

설치 파일은 `dist\installer\`에 생성됩니다. Inno Setup 컴파일러가 없으면 `Get-InstallerCompiler.ps1`이 공식 7.1.0 배포 파일의 고정 SHA256과 Authenticode 서명을 확인한 후 `.tools`에 준비합니다. 이미 설치한 컴파일러는 `-CompilerPath`로 지정할 수 있습니다. 빌더의 라이선스는 [Inno Setup 안내](https://jrsoftware.org/isdl.php)를 따릅니다.

핵심 검사는 `dotnet run --project Switchit.Core.Tests\Switchit.Core.Tests.csproj`, 숨김 WPF 검사는 `dotnet run --project Switchit.UI.Tests\Switchit.UI.Tests.csproj -- artifacts\ui`로 실행합니다. GitHub Actions에서도 검사와 설치 파일 빌드를 수행합니다. 사용자 기록, `.qa`, `.tools`, `bin`, `obj`, `dist`는 Git에 포함하지 않습니다.

`scripts\Generate-Icon.py`는 Python 표준 라이브러리만 사용해 원본 픽셀 아이콘을 다시 생성합니다. 작업 및 배포 내역은 `history.md`에 한 줄씩 기록합니다.
